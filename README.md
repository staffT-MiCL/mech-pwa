# 重装機体

PS初期風のローポリで描く3Dロボアクション。フレーム（ヘッド・コア・アーム・レッグ）と兵装を組み替え、演習場で標的機と戦います。three.js（r186）を使用し、スマホとPCの両方で遊べるPWAです。

## 遊び方
- ガレージ：左の機体の部位ボタンを押すと、右側で装備を選べる（現在の装備との差を表示）
- 右上の MENU から「出撃」（標的機が反撃する）または「試運転」（反撃なし）
- スマホ：左下のスティックで移動、三角で急加速、右下のボタンで武器と跳躍
- PC：WASD 移動（同じキー2回で急加速）／Shift ダッシュ／Space 跳躍／J・K・L 武器／マウスドラッグで視点

## 構成
- `index.html` ゲーム本体
- `vendor/` three.js（MIT License）
- `manifest.webmanifest`・`sw.js` PWA設定（オフライン対応）

## 公開
GitHub Pages（main ブランチのルート）で配信。更新時は `sw.js` の `CACHE` の番号を上げると、端末の保存分が入れ替わります。
